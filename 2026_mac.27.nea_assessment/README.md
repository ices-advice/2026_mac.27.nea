# 2026_mac.27.nea_assessment
2026 - Mackerel (Scomber scombrus) in subareas 1-8 and 14 and in divisions 9.a, 12.a, and 12.b (Northeast Atlantic and adjacent waters)  - WGWIDE (ADGWIDE)


## Naming convention for the data prep
Data script      | Description
-----------|--------------
**Models 0.x**| **Data revisions**
data0.00.r     | 	reproducing the data for the accepted assessment at WGIWDE 2025.
data0.01.r     | 	loading the updated data for the 2026 WGWIDE assessment.
data0.02.r     | 	loading the updated data for the 2026 WGWIDE assessment, with tag index at 12+.
data0.03.r     | 	loading the updated data for the 2026 WGWIDE assessment, with the stock weights not using the egg survey data.


## Naming convention for the model runs

Model      | Description
-----------|--------------
**Models 0.x**| **Data revisions**
model0.00     | 	reproducing the accepted assessment at WGWIDE 2025.
model0.00.rev | 	reproducing the accepted assessment at WGWIDE 2025 with the updated MEGS SSB index 2025.
model0.01     | 	model using the new 2026 WGWIDE data.
model0.02     | 	model using the new 2026 WGWIDE data, with tag index at age 12+.
model0.03.r     | 	loading the updated data for the 2026 WGWIDE assessment, with the stock weights not using the egg survey data.
